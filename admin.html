📤 Terbitkan Perubahan (wajib setiap selesai edit)

GitHub Pages tidak punya database — jadi hasil edit perlu di-paste ke file spots.json di repo. Simpel kok, cuma 5 langkah: 

{"spots":[]}
  1. Buka file spots.json di GitHub
  2. Klik ikon pensil ✏️ (Edit file) di pojok kanan atas
  3. Pilih semua isinya (Ctrl+A), lalu tempel JSON yang sudah kamu salin (Ctrl+V)
  4. Klik tombol hijau Commit changes (tulis "Update links" di kotak pesan, lalu Commit)
  5. Tunggu ±1 menit — situs otomatis ter-update 🎉
